### 1. النموذج الرياضي للقناة (System Model)

لنظام اتصالات متعدد المداخل والمخارج ($MIMO$) يمتلك $N_t$ هوائيات إرسال و $N_r$ هوائيات استقبال ($N_t = N_r = 4$):

$$\mathbf{y} = \mathbf{H}\mathbf{x} + \mathbf{n}$$

حيث:
* $\mathbf{y} \in \mathbb{C}^{N_r \times 1}$: شعاع الإشارة المستقبلة.
* $\mathbf{x} \in \mathbb{C}^{N_t \times 1}$: شعاع الإشارة المرسلة.
* $\mathbf{H} \in \mathbb{C}^{N_r \times 1}$: مصفوفة القناة العشوائية، وعناصرها $h_{ij} \sim \mathcal{CN}(0, 1)$ مستقلة ومتطابقة التوزيع (i.i.d. Rayleigh fading).
* $\mathbf{n} \in \mathbb{C}^{N_r \times 1}$: ضجيج غاوسي أبيض متماثل قطرياً $\mathbf{n} \sim \mathcal{CN}(\mathbf{0}, \sigma_n^2 \mathbf{I}_{N_r})$.

قيد القدرة الكلية للإرسال يُعطى بالعلاقة:

$$\mathbb{E}\left[\|\mathbf{x}\|^2\right] = \operatorname{Tr}(\mathbf{R}_{xx}) \le P$$

حيث $\mathbf{R}_{xx} = \mathbb{E}\left[\mathbf{x}\mathbf{x}^H\right]$ هي مصفوفة التغاير (Covariance matrix) للإشارة المرسلة.

---

### 2. اشتقاق المعلومات المتبادلة (Mutual Information)

تُعرّف المعلومات المتبادلة $I(\mathbf{x}; \mathbf{y} \mid \mathbf{H})$ بدلالة الإنتروبيا التفاضلية:

$$I(\mathbf{x}; \mathbf{y} \mid \mathbf{H}) = h(\mathbf{y} \mid \mathbf{H}) - h(\mathbf{y} \mid \mathbf{x}, \mathbf{H})$$

بما أن $\mathbf{y} \mid (\mathbf{x}, \mathbf{H}) = \mathbf{H}\mathbf{x} + \mathbf{n}$، فإن التشتت حول الإشارة المرسلة ناتج عن الضجيج فقط:

$$h(\mathbf{y} \mid \mathbf{x}, \mathbf{H}) = h(\mathbf{n}) = \log_2 \det(\pi e \sigma_n^2 \mathbf{I}_{N_r})$$

لتحقيق الحد الأعلى للإنتروبيا $h(\mathbf{y} \mid \mathbf{H})$ تحت قيد التغاير المحدد، يجب أن تكون الإشارة $\mathbf{x}$ متغيرة عشوائية غاوسية دائرية مركبة $\mathbf{x} \sim \mathcal{CN}(\mathbf{0}, \mathbf{R}_{xx})$، مما يجعل $\mathbf{y}$ غاوسية أيضاً بتغاير:

$$\mathbf{R}_{yy} = \mathbb{E}\left[\mathbf{y}\mathbf{y}^H \mid \mathbf{H}\right] = \mathbf{H}\mathbf{R}_{xx}\mathbf{H}^H + \sigma_n^2 \mathbf{I}_{N_r}$$

بالتالي:

$$h(\mathbf{y} \mid \mathbf{H}) = \log_2 \det\left(\pi e \left(\mathbf{H}\mathbf{R}_{xx}\mathbf{H}^H + \sigma_n^2 \mathbf{I}_{N_r}\right)\right)$$

بطرح المقدارين، نحصل على سعة القناة اللحظية:

$$I(\mathbf{x}; \mathbf{y} \mid \mathbf{H}) = \log_2 \det\left(\mathbf{I}_{N_r} + \frac{1}{\sigma_n^2} \mathbf{H}\mathbf{R}_{xx}\mathbf{H}^H\right)$$

---

### 3. إثبات التوزيع المتساوي للقدرة (CSIR Only)

عندما تتوفر معلومات حالة القناة عند المستقبل فقط (**CSIR**) وتغيب تماماً عن جهاز الإرسال (**No CSIT**):

1. توزيع مصفوفة القناة $\mathbf{H}$ غير مترابط، وهو متناظر دورانياً (Unitarily Invariant):
   $$\mathbf{H} \sim \mathbf{H}\mathbf{U}$$
   لأي مصفوفة أحادية ثابتة $\mathbf{U} \in \mathbb{U}(N_t)$.
2. دالة السعة محدبة عكساً (Concave) بالنسبة لـ $\mathbf{R}_{xx}$. بتطبيق متباينة ينسن (Jensen's Inequality) ومبدأ التناظر الإحصائي، يكون التوزيع الأمثل للقدرة هو التوزيع المتكافئ عبر جميع هوائيات الإرسال:

$$\mathbf{R}_{xx} = \frac{P}{N_t} \mathbf{I}_{N_t}$$

بتعريف متوسط نسبة الإشارة إلى الضجيج عند كل فرع استقبال بـ $\rho = \frac{P}{\sigma_n^2}$، تصبح السعة اللحظية:

$$C(\mathbf{H}) = \log_2 \det\left(\mathbf{I}_{N_r} + \frac{\rho}{N_t} \mathbf{H}\mathbf{H}^H\right)$$

وبأخذ التوقع الرياضي $\mathbb{E}[\cdot]$ على جميع التحققات العشوائية لـ $\mathbf{H}$ (قناة رايلي ذات خفوت سريع Ergodic Channel)، نحصل على **السعة الإرجودية**:

$$C = \mathbb{E}_{\mathbf{H}}\left[\log_2 \det\left(\mathbf{I}_{N_r} + \frac{\rho}{N_t} \mathbf{H}\mathbf{H}^H\right)\right]$$

---

### 4. التفكيك الطيفي والقنوات المكانية المكافئة (Eigenmode Decomposition)

باستخدام متطابقة سيلفستر للمحددات ($\det(\mathbf{I}_m + \mathbf{A}\mathbf{B}) = \det(\mathbf{I}_n + \mathbf{B}\mathbf{A})$):

$$\det\left(\mathbf{I}_{N_r} + \frac{\rho}{N_t} \mathbf{H}\mathbf{H}^H\right) = \det\left(\mathbf{I}_{N_t} + \frac{\rho}{N_t} \mathbf{H}^H\mathbf{H}\right)$$

المصفوفة $\mathbf{W} = \mathbf{H}\mathbf{H}^H$ (أو $\mathbf{H}^H\mathbf{H}$) هي مصفوفة ويشارت هيرميتية مركزية وتكون موجبة نصف معرفة ($Wishart \ Matrix$). التحليل الطيفي لها يعطي:

$$\mathbf{W} = \mathbf{U} \mathbf{\Lambda} \mathbf{U}^H, \quad \mathbf{\Lambda} = \operatorname{diag}(\lambda_1, \lambda_2, \dots, \lambda_{r})$$

حيث $r = \min(N_t, N_r) = 4$، و $\lambda_i \ge 0$ هي القيم الذاتية (Eigenvalues). يتحول المحدد إلى جداء:

$$\det\left(\mathbf{I} + \frac{\rho}{N_t} \mathbf{\Lambda}\right) = \prod_{i=1}^{4} \left(1 + \frac{\rho}{4}\lambda_i\right)$$

وبإدخال اللوغاريتم:

$$C = \mathbb{E}\left[\sum_{i=1}^{4} \log_2 \left(1 + \frac{\rho}{4}\lambda_i\right)\right] = \sum_{i=1}^{4} \mathbb{E}\left[\log_2 \left(1 + \frac{\rho}{4}\lambda_i\right)\right]$$

حيث يُعامل النظام كـ $4$ قنوات افتراضية متوازية مستقلة ذات كسب طاقي متناظر مع القيم الذاتية $\lambda_i$.

---

### 5. السلوك التقاربي لنظام $4 \times 4$ (Asymptotic Limits)

#### أ. عند نسبة إشارة إلى ضجيج عالية ($\rho \to \infty$):
$$\log_2\left(1 + \frac{\rho}{4}\lambda_i\right) \approx \log_2\left(\frac{\rho}{4}\right) + \log_2(\lambda_i)$$

$$C \approx 4 \log_2(\rho) + \sum_{i=1}^{4} \mathbb{E}[\log_2(\lambda_i)] - 4\log_2(4)$$

* **درجات الحرية (Degrees of Freedom):** ميل المنحنى يساوي $4$ بت/ثانية/هرتز لكل $3 \text{ dB}$ زيادة في قدرة الإرسال، وهو ما يمثل مكسب التجميع المكاني الكامل ($Spatial \ Multiplexing \ Gain = \min(N_t, N_r) = 4$).

#### ب. عند نسبة إشارة إلى ضجيج منخفضة ($\rho \to 0$):
باستخدام النشر بالمتسلسلة $\ln(1 + x) \approx x$:

$$C \approx \frac{1}{\ln 2} \frac{\rho}{4} \mathbb{E}\left[\sum_{i=1}^{4} \lambda_i\right] = \frac{\rho}{4 \ln 2} \mathbb{E}[\operatorname{Tr}(\mathbf{H}\mathbf{H}^H)]$$

بما أن عناصر $\mathbf{H}$ ذات تباين أحادي: $\mathbb{E}[|h_{ij}|^2] = 1$:

$$\mathbb{E}[\operatorname{Tr}(\mathbf{H}\mathbf{H}^H)] = \sum_{i=1}^{4}\sum_{j=1}^{4} \mathbb{E}[|h_{ij}|^2] = 4 \times 4 = 16$$

$$C \approx \frac{\rho}{4 \ln 2} \times 16 = \frac{4\rho}{\ln 2} \quad (\text{bits/s/Hz})$$

---

### 6. التحقق العددي والمحاكاة

يقوم الكود التالي بمحاكاة مونت-كارلو لحساب السعة الإرجودية ومقارنة نظام $4\times 4$ مع نظام الهوائي الواحد ($SISO$):

```python:plot
import numpy as np
import matplotlib.pyplot as plt

# MAE Academy Official Palette
COLOR_BLUE = '#2563EB'
COLOR_PURPLE = '#7C3AED'
COLOR_RED = '#DC2626'

plt.style.use('seaborn-v0_8-whitegrid' if 'seaborn-v0_8-whitegrid' in plt.style.available else 'default')
plt.rcParams['font.sans-serif'] = ['Inter', 'Arial', 'DejaVu Sans', 'sans-serif']
plt.rcParams['axes.edgecolor'] = '#E2E8F0'
plt.rcParams['axes.linewidth'] = 1.2

np.random.seed(0)

# SNR grid in dB
snr_db = np.linspace(-10, 30, 200)
snr_linear = 10.0 ** (snr_db / 10.0)

Nt, Nr = 4, 4
num_trials = 2000

# Monte-Carlo realization of Rayleigh channel matrices
H_trials = (np.random.randn(num_trials, Nr, Nt) + 1j * np.random.randn(num_trials, Nr, Nt)) / np.sqrt(2.0)
W_trials = np.matmul(H_trials, np.swapaxes(H_trials.conj(), 1, 2))  # H * H^H

# Compute eigenvalues for each trial
eigvals = np.linalg.eigvalsh(W_trials)  # shape: (num_trials, 4)

# Ergodic Capacity calculation
C_mimo = np.zeros(len(snr_linear))
C_siso = np.zeros(len(snr_linear))

# SISO reference: h ~ CN(0, 1) -> |h|^2 ~ Exponential(1)
h_siso_sq = np.random.exponential(scale=1.0, size=num_trials)

for idx, rho in enumerate(snr_linear):
    # MIMO 4x4 with equal power allocation
    c_inst_mimo = np.sum(np.log2(1.0 + (rho / Nt) * eigvals), axis=1)
    C_mimo[idx] = np.mean(c_inst_mimo)
    
    # SISO reference
    c_inst_siso = np.log2(1.0 + rho * h_siso_sq)
    C_siso[idx] = np.mean(c_inst_siso)

# High-SNR asymptotic line for 4x4
log_det_W = np.mean(np.sum(np.log2(eigvals), axis=1))
C_asymptotic = 4.0 * np.log2(snr_linear / Nt) + log_det_W

fig, ax = plt.subplots(figsize=(8, 4.5), constrained_layout=True)

ax.plot(snr_db, C_mimo, color=COLOR_RED, linewidth=2.5, label=r'Ergodic Capacity $4\times 4$ MIMO')
ax.plot(snr_db, C_asymptotic, color=COLOR_PURPLE, linestyle='--', linewidth=1.8, label=r'High-SNR Asymptote ($S = 4$)')
ax.plot(snr_db, C_siso, color=COLOR_BLUE, linewidth=2.0, label=r'Ergodic Capacity $1\times 1$ SISO')

ax.set_title(r'Ergodic Capacity of Rayleigh Channel ($4\times 4$ MIMO vs. SISO)')
ax.set_xlabel(r'Average SNR $\rho$ (dB)')
ax.set_ylabel(r'Spectral Efficiency (bits/s/Hz)')
ax.set_ylim(0, 40)
ax.grid(True, linestyle='--', alpha=0.6)
ax.legend(loc='upper left')
```
