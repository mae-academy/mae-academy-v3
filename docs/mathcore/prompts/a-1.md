## Constraints for this step

This step covers Phase 0 items 1–4 only (docs/mathcore/STEPS.md, Section 11). D1 specs are recorded in STEPS.md, but device measurements are item 5: do not run them; record them as 'not measured'.

- **Compute Engine:** `@cortex-js/compute-engine@0.58.0` is owner-approved and already installed and pinned in `package.json` (the version MathLive uses). Do not install, upgrade or add any other version. Verify against 0.58.0, and record the results in `docs/mathcore/reports/a-1-measurements.md`:
  - the MathJSON shape of `Matrix` (2×2 and 3×3) and of the derivative head `D` (as in `\frac{dy}{dx} = x - y`);
  - that the `canonical: false` parse option exists and behaves as ADR-2 assumes. If any shape or option differs from the plan, report it and stop.
- **Golden corpus:** write the generator only, in `scripts/mathcore/oracle/`. Do not run it and do not write any file under `shared/mathcore/__golden__/`; the owner runs the generator and commits the output.
- **mpmath:** owner-approved as a Python dependency. It lives in a separate Python environment (for example a venv), never in `package.json`. Document how to create that environment next to the generator.
