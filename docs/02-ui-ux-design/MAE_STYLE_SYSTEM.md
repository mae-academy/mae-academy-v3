# نظام MAE البصري — عقد التوسّع

## جوهر الأسلوب

يجب أن تبقى أكاديمية MAE في إطار **Luminous Technical Atelier**: تجربة تحريرية هندسية داكنة، دقيقة، ومتحركة بهدوء. لا تُعامل الواجهة كقالب SaaS؛ بل كلوحة بحث هندسي ذات محطات واضحة، إشارات معايرة، وأدلة بصرية تقود المستخدم عبر النمذجة والتحليل والهندسة.

## الألوان والمواد

الخلفية الأساسية هي حبر تقني عميق (`#07111F`) في الوضع الداكن، وورق هندسي بارد (`#F7F8FC`) في الوضع الفاتح. يبقى التدرج الأزرق–البنفسجي–القرمزي **تيارًا إرشاديًا** وليس زينة موزعة بلا هدف. يستعمل فقط للأفعال الأساسية، المسار النشط، عُقد المخططات، وفواصل الأقسام ذات الأهمية.

| العنصر | قاعدة التنفيذ |
|---|---|
| الخلفيات | طبقات شفافة، ضباب لوني منخفض الكثافة، وشبكة هندسية خفيفة. |
| البطاقات | حواف هادئة، زوايا `rounded-2xl`، وارتفاع بسيط عند التأشير. |
| الأزرار الأساسية | كبسولة متدرجة، ظل بنفسجي محدود، واستجابة ضغط `scale` بسيطة. |
| الأزرار الثانوية | سطح شفاف أو أبيض مخفف، حد واضح، ولا تستخدم تدرجًا ممتدًا. |

## الخطوط واللغة

تُستخدم **Apple Gothic** أو البديل النظامي المتوافق للإنجليزية والإسبانية. العربية تستخدم **Tajawal** فقط. كل نص جديد يجب أن يُضاف إلى `client/src/data/content.ts` باللغات الثلاث قبل استخدامه. لا تضف نصًا مرئيًا ثابتًا داخل صفحة أو مكوّن.

> العربية تغيّر اتجاه الوثيقة كاملًا إلى `rtl`، بينما الإنجليزية والإسبانية تستخدمان `ltr`. يجب اختبار أي مكوّن جديد في الاتجاهين قبل اعتباره مكتملًا.

## البنية المعمارية

المحتوى المترجم موجود في `client/src/data/content.ts`، وحالة اللغة متاحة عبر `useLocale()`. عناصر التنقل ومسارات المنصة في `client/src/data/platform.ts`. صفحات المجموعات تستخدم `CardGridPage` بدل نسخ البطاقات. عند إدخال ملفات أو محتوى جديد، حوّله أولًا إلى بنية بيانات مترجمة، ثم اربطه بصفحة أو مكوّن قائم.

## الرسومات والحركة

تستخدم MAE رسومات SVG أصلية فقط. لا تضع صورًا نقطية أو صورًا مولّدة. يجب أن ترتبط الرسومات التقنية بمحتواها الفعلي: خريطة أدلة للبحث، مسار تقدّم للدورات، أو منصة اختبار للمحاكاة.

الحركة تخدم الانتقال والفهم. استخدم `opacity` و`transform` فقط، ضمن مدد قصيرة غالبًا. انتقال المسار هو كاميرا أفقية، وتبديل اللغة هو مسح اتجاهي يطابق انتقال الواجهة بين LTR وRTL. المخطط الرئيسي يستجيب للتأشير أو التركيز بتحريك العُقد والمسارات والإحداثيات، لا بحركة عشوائية مستمرة.

## قائمة مراجعة قبل إضافة محتوى

- أضف نسخة إنجليزية وعربية وإسبانية لكل نص مرئي أو وصفي.
- استخدم `useLocale()` ولا تترك نصوصًا ثابتة في JSX.
- حافظ على التسميات الصغيرة، الإحداثيات، ورقم المحطة كوحدات تنظيمية.
- استخدم المكونات المشتركة والرموز الموجودة قبل إنشاء عناصر بديلة.
- اختبر العرض في العربية والإسبانية، وعلى الهاتف وسطح المكتب.
- اسأل دائمًا: هل يعزّز هذا الاختيار منطق الاستوديو الهندسي المضيء، أم يضعفه؟
